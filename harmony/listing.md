## Game title
Arrow Escape

## Description
Every board is packed with arrows. Tap one and it slides off the board in the direction it points. But if another arrow is in the way, it bumps, and you lose a heart.

Work out the right order and clear the board to move on to the next level. Lose all five hearts and the level starts over. Stuck? Tap Hint to see an arrow that's free to go.

Calm, clever logic puzzles with no timer and no end, and every level gets a little trickier.

Controls
- Mobile: tap an arrow to send it flying.
- Desktop: click an arrow to send it flying.
